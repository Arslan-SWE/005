⚡ نەمۇنە كود: Python Port Scanner

تۆۋەندىكى كود ئارقىلىق مەلۇم بىر ئىچكى تور ئادرېسىنىڭ ئوچۇق ئېغىزلىرىنى سىناپ كۆرەلەيسىز: 

import socket

target = "127.0.0.1"
ports = [21, 22, 80, 443, 8080]

print(f"Scanning target: {target}")
for port in ports:
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.settimeout(1)
    result = sock.connect_ex((target, port))
    if result == 0:
        print(f"[+] Port {port}: OPEN")
    else:
        print(f"[-] Port {port}: CLOSED")
    sock.close()
